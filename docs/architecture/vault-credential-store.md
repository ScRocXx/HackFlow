# Vault Credential Store & Registration Utilities

The Vault is HackFlow's centralized repository for competition assets, team member bios, student roll numbers, and submission links.

## 1. Tactical Registration Flow

Student hackathons frequently demand repeated manual entry of the same repetitive information across disparate platforms (Devfolio, Unstop, HackerEarth, Google Forms).

The Vault provides 1-click clipboard utilities for:
- Full Legal Name & College Roll / Registration Number
- Degree, Branch, and Graduation Year
- GitHub Profile, LinkedIn, and Resume URLs
- Primary Discord / Telegram Handles and Emergency Phone Contacts

## 2. Resource Shelf & Squad Scratchpad

Beyond static profiles, the Vault contains:
- **Resource Shelf**: Curated problem statements, rulebooks, starter kits, and design system kits.
- **Squad Scratchpad**: A shared, multi-user temporary note space for credentials, deployment endpoints, and testing credentials during high-pressure sprints.
- **IndexedDB Local Cache**: Offline-first persistent storage ensuring team members never lose pasted API keys or draft notes if network connectivity fluctuates during the event.
