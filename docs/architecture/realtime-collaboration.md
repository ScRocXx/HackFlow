# Realtime Collaboration & Event Channels

HackFlow provides multi-user real-time synchronization across hackathon teams using Supabase Realtime channels multiplexed by event room.

## 1. Single Channel Multiplexing

Rather than opening separate WebSocket subscriptions for deliverables, stages, and team chat, all workspace events within a competition are multiplexed over a single topic:

```
room:event:{eventId}
```

### Supported Event Types
1. **Deliverables**:
   - `INSERT`: Optimistic task additions reconciled with Postgres autogenerated IDs.
   - `UPDATE`: Realtime status toggles (`is_done`) and task claiming (`assigned_to`).
   - `DELETE`: Instant removal across all connected squad members.
2. **Stage Progression**:
   - `STAGE_ADVANCE`: Triggers active stage recalibration without requiring a full page refresh.
3. **Presence & Squad Sync**:
   - Lightweight typing and view indicators for shared deliverables and pitch notes.

## 2. Zero-Latency Optimistic Updates with Rollback

To maintain maximum responsiveness under congested venue Wi-Fi:
1. **Immediate State Transition**: The client state mutates instantly upon user input (checkbox click, reorder, or text submission).
2. **Server Action Dispatch**: Asynchronous mutation is transmitted via Next.js Server Action (`toggleDeliverable`, `claimDeliverable`, etc.).
3. **Graceful Rollback**: If the server rejects the mutation (network failure or authorization error), the client reverts to the previous snapshot and displays a notification.
